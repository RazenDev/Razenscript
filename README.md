✦ About

Razen Hub is a dark, premium-style Lua GUI project designed with a clean interface, organized tabs, and customizable settings.

Features

- 📑 Organized tabs for supported games
- 🎮 Automatic game detection interface
- 🎯 Configurable ESP interface for Murder Mystery 2
- 🥚 Dedicated Steal an Egg tab
- ⚙️ Universal movement settings interface
- 🎚️ Numeric controls and sliders
- 🔔 Feature-toggle notifications
- 🖱️ Draggable window
- ⌨️ "RightShift" interface toggle

🎮 Supported Game Tabs

📦 Installation

1. Download "RazenHub.lua" from this repository.
2. Review the source code before running it.
3. Use it only in an environment and game you own or are authorized to test.
